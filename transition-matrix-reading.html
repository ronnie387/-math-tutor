Section 01

從一個真實問題出發

假設我們正在研究某個地區的人口流動。每一年，城市和鄉村的居民都會有一部分人搬家，這種「狀態之間的轉換」，正是轉移矩陣想要描述的事情。

情境設定

某地區有城市與鄉村兩種居住地。根據統計：

  • 住在城市的人，每年有 85% 留在城市，15% 搬到鄉村
  • 住在鄉村的人，每年有 20% 搬到城市，80% 留在鄉村

注意：每個出發地的機率加起來必須等於 100%。城市的 85% + 15% = 100%，鄉村的 20% + 80% = 100%。這是轉移矩陣的基本要求。

Section 02

把數字整理成矩陣

我們可以把這些機率，整齊地排入一個 2×2 的矩陣中。這個矩陣就叫做轉移矩陣（Transition Matrix）。

從鄉村出發

✦ 每一欄的數字總和 = 1（100%） |  把滑鼠移到數字上查看含義
第一欄（從城市出發）

0.85：城市 → 城市（留下）
0.15：城市 → 鄉村（離城）
合計：0.85 + 0.15 = 1.00

第二欄（從鄉村出發）

0.20：鄉村 → 城市（進城）
0.80：鄉村 → 鄉村（留下）
合計：0.20 + 0.80 = 1.00

Section 03

轉移矩陣的正式定義

定義

設系統有 n 種狀態。轉移矩陣 T 是一個 n × n 的矩陣，其中：

第 i 列、第 j 欄的元素 tij，表示系統從狀態 j 轉移到狀態 i 的機率。

由於機率的性質，每一欄的所有元素之和必須等於 1：

t1j + t2j + … + tnj = 1，對所有 j 成立

此外，所有元素都必須介於 0 和 1 之間（因為它們是機率）。
滿足以上條件的矩陣，稱為隨機矩陣（Stochastic Matrix）。

掌握這個定義後，你就能用矩陣的方式，計算若干年後的人口分布。例如，若今年人口向量為 x，明年的分布就是 T × x。

Section 04

白話文結語

🗣️ 用人話說一遍

轉移矩陣，其實就是一張「搬家機率表」。

想像你在管理一個城市規劃模擬遊戲。每年結束時，你需要算出明年城市和鄉村各有多少人——問題是，人會搬來搬去。

轉移矩陣的任務，就是把「每種人搬家的機率」整理成一張乾淨的表格。欄告訴你這個人現在住哪裡（出發地），列告訴你他可能搬到哪裡（目的地）。

每一欄加起來等於 1，是因為不管這個人住在哪裡，他下一年一定住在「某個地方」——機率不會憑空消失。

有了這張表，只要知道今年有多少人住在城市、多少人住在鄉村，就能用矩陣乘法直接算出明年的人口分布。這就是轉移矩陣最強大的地方：讓複雜的人口流動，變成一行數學式。
